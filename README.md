# capisante.com

Renvoi de **capisante.com** et **www.capisante.com** vers le site Santéo : https://www.santeo.net

Ce dépôt ne contient que de petites pages de renvoi (accueil, `/cgu`, `/mentions-legales`, et toute autre adresse),
publiées par GitHub Pages avec un certificat (cadenas). Les lignes mail de capisante.com (MX, SPF) ne dépendent pas de
ce dépôt et ne sont jamais modifiées par lui. capisante.fr (relais du comparateur) n'est pas concerné.
